How the model scores a card

Momentum (25%), price discount to recent weighted median (30%), demand via recent transaction volume (20%), volatility/risk (15%) and price-data depth (10%). Low sample sizes downgrade confidence. BUY and SELL labels only activate once enough recent comparable sales are supplied. The engine does not infer hype from social media until measurable data is integrated.

Settings & integrations

Create a free Supabase project and run supabase.sql from this download. Enter the project URL and its public anon/publishable key below. Never paste a service-role key or a paid pricing API secret.

For magic links, allow your GitHub Pages URL in Supabase Authentication URL Configuration.

Local backup

Export or import collection, watchlist and manual completed-sale records. Download backups before clearing browser data.

Price data integrity

The free TCGdex API supplies card identities, images and some USD/EUR market quotes. A USD market quote is not a GBP verified sale. Prices unavailable from the provider show “No data”. User-supplied GBP sold comps drive all-time observed high/low and research signals. PSA values are not guessed.

Tradr151 is an independent collector research tool, not affiliated with Trading 212, Pokémon, Nintendo, PSA or marketplace providers. Signals are research indicators, not guarantees of future value.
